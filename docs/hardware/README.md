# Hardware y Pinout (`docs/hardware/`)

Documenta las conexiones físicas, niveles de tensión y precauciones de las 4 tarjetas del proyecto:

- [`pinout.md`](pinout.md): asignación de placas (`2× ESP32-C6-DevKitC-1`, `1× ESP32-C6 SuperMini`, `1× ESP32-S3 N16R8 UNO`), pines reservados/prohibidos (Octal PSRAM `GPIO 33–37`, Flash, USB), mapeo exacto de RC522 (3.3V), PIR HC-SR501 (5V/3.3V), DHT11 (3.3V) y código unificado de colores del LED RGB.
